# ✈️ 编程纸飞机作战

一款基于 Phaser 3 的飞行射击游戏，融合了编程八股文答题系统。

## 📁 项目结构

```
paper-plane/
├── index.html                  # 主入口
├── README.md                   # 项目说明
└── js/
    ├── constants.js            # 常量配置（所有魔法数字集中管理）
    ├── config.js               # 题库数据 + 成就定义
    ├── data-store.js           # 数据持久化（localStorage）
    ├── player-info.js          # 玩家信息管理
    ├── achievements.js         # 成就检测逻辑
    ├── game.js                 # Phaser 游戏启动
    │
    ├── managers/               # 管理器模块
    │   ├── SoundManager.js     # 音效管理（Web Audio API）
    │   ├── InputManager.js     # 输入管理（键盘 + 触屏）
    │   ├── UIManager.js        # UI 管理（HUD、血条、技能栏）
    │   └── VFXManager.js       # 视觉效果（星空、爆炸、粒子）
    │
    ├── systems/                # 系统模块
    │   ├── SkillSystem.js      # 技能系统（护盾、炸弹、时间减缓）
    │   └── QuizSystem.js       # 答题系统（题目显示、选项交互）
    │
    ├── entities/               # 实体模块（预留）
    │
    └── scenes/                 # 场景模块
        ├── BootScene.js        # 启动场景（资源加载）
        ├── LoginScene.js       # 登录场景
        ├── MenuScene.js        # 主菜单
        ├── RankScene.js        # 排行榜
        ├── SettingsScene.js    # 设置界面
        ├── StatsScene.js       # 统计界面
        ├── AchScene.js         # 成就界面
        ├── GameScene.js        # 游戏主场景
        └── OverScene.js        # 游戏结束
```

## 🎮 游戏特性

### 核心玩法
- ⬆️⬇️⬅️➡️ / WASD - 移动
- 空格 / 点击 - 射击
- E - 护盾技能
- Q - 炸弹技能
- R - 时间减缓技能

### 游戏系统
- 🌊 **波次系统** - 难度逐渐提升
- ❓ **答题系统** - 90+ 道编程八股文
- 🎯 **成就系统** - 22 种成就挑战
- 🏆 **排行榜** - 本地最高分记录
- ⚙️ **设置系统** - 音效、难度、自动射击

### 道具类型
- 🔫 **弹药** - 补充子弹
- ❤️ **生命** - 恢复血量
- 📝 **答题卡** - 答题赢取子弹
- 🛡️ **护盾** - 临时无敌
- 🔀 **散射** - 三发子弹
- ✨ **双倍分** - 得分翻倍

## 🛠️ 技术架构

### 设计模式
- **管理器模式** - 各系统独立管理
- **组件化** - 功能模块解耦
- **常量配置** - 集中管理游戏参数

### 代码优化
- ✅ 模块化拆分（原 103KB 单文件 → 14 个模块）
- ✅ 常量提取（消除魔法数字）
- ✅ 命名规范化（完整单词代替缩写）
- ✅ 注释完善（JSDoc 文档）
- ✅ 架构分层（Manager / System / Scene）

### 性能优化建议
- 使用对象池管理频繁创建的粒子
- 降低星空背景更新频率
- 使用 Sprite 替代频繁 clear 的 Graphics

## 🚀 快速开始

1. 直接在浏览器中打开 `index.html`
2. 输入昵称登录
3. 点击「开始游戏」
4. 使用键盘或触屏操控飞机
